# 🟡 吃豆人 Pac-Man

经典的吃豆人游戏，纯 HTML/CSS/JavaScript 实现，无需任何依赖，直接在浏览器中打开即可游玩。

## 🎮 玩法

- **↑↓←→** 或 **WASD** 控制吃豆人移动
- 吃掉所有豆子即可通关
- 吃到**能量豆**（大颗闪烁豆子）可以反杀幽灵
- 避开幽灵，被抓住会失去生命
- **空格** 暂停 | **R** 重新开始

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可：

```bash
# 或者用 Python 启动本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🎨 特性

- 经典迷宫布局与幽灵 AI 行为
- 四种不同颜色的幽灵，各有独特的追踪策略
- 能量豆系统（吃后幽灵变蓝可被吃掉）
- 最高分本地存储
- 键盘 + 触屏双操控
- 简易音效反馈
